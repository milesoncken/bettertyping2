What was actually wrong

Recorded so the rewrite is judged against real defects rather than taste. Every line below is from the current codebase.

Architecture

Structural

State lives in the DOM. The engine mutates classList on live nodes and reads truth back out of them. React is a shell wrapped around imperative DOM writes; every downstream feature inherits that fragility. TextArea.jsx — document.getElementsByClassName("letter")[i].classList.add("correct")

Structural

Line wrapping is derived from geometry. Bounding-rect comparisons decide when a line broke, and scrolling is a negative margin. Layout-dependent, resize-fragile, untestable. TextArea.jsx — getOffset(nextLetter).top > getOffset(currentLetter).top

Structural

Words are stored as React elements in state. Model and view are the same object, so the word list can't be reasoned about, serialized, or verified. TextArea.jsx — setWordList(elements)

Structural

A numeric state machine — -1, 0, 1, 3, 4, 5, with no 2 — coordinated across roughly thirteen effects in two components. Test.jsx — "weird things happen (its sent twice) ... i have no idea awhy"

Correctness

Bug

Accuracy never forgives a correction. Backspace clears the CSS classes and steps the index back, but never pops the letter from the correct/incorrect arrays. Fix a typo and you are charged for the mistake and the fix, permanently. TextArea.jsx — currentIncorrectLetterArray is append-only

Bug

The headline metric isn't WPM. (correct − incorrect) / 5 / min double-penalizes every error, can go negative, and is comparable to no other site on earth. Test.jsx — trueWPM

Bug

The chart is sampled by a live interval, so results depend on when ticks landed. Nothing is reproducible, which is precisely why nothing can be verified. Test.jsx — setChartData inside setInterval

Bug

Timing uses wall-clock time. Date.now() is subject to NTP corrections and coarser resolution; keystroke timing needs a monotonic clock. TextArea.jsx — const now = Date.now()

Integrity & product

Integrity

The leaderboard is forgeable in one command. The client computes its own results, sets its own isValid flag, reports the word list it claims it was given, and POSTs the whole object. Test.jsx — sendTestToBackend(test)

Dead code

646 lines of difficulty word lists with no route to them. Difficulty is hardcoded "normal" in the reset; easy and hard have never once been reachable. wordLists.js / Test.jsx

Analysis

The heatmap measures noise. Each key is coloured by its single slowest keystroke of the test — one hesitation defines a key forever. The signal is the median, not the max. Heatmap.jsx — if (event.delay > counts[key].delay)

The typing engine

A pure reducer. No DOM, no React, no timers. React subscribes to it; it never subscribes to React.

type Phase = 'idle' | 'ready' | 'running' | 'finished';

interface EngineState {
  phase:   Phase;
  words:   Word[];            // { target, typed[], extra[] }
  cursor:  { word: number; char: number };
  events:  KeyEvent[];        // append-only, monotonic
  startedAt: number | null;
}

interface KeyEvent {
  t:      number;             // ms since first keystroke, float
  code:   string;             // physical key — layout independent
  key:    string;             // produced character
  hold?:  number;             // keyup − keydown
  target: string | null;      // expected char at the time
  kind:   'char' | 'backspace' | 'word-back' | 'space';
}

Rules v1 gets right

  • Backspace genuinely reverts state. Correctness is derived from the event log, never accumulated in mutable arrays.
  • Two accuracy figures, both reported: firstAttemptAccuracy (the industry-comparable number) and finalAccuracy. Corrections count against the first — never against WPM.
  • Extra characters are supported. Typing past a word appends marked-extra glyphs instead of silently advancing.
  • Space skips the word and marks the remainder missed. Backspace crosses a word boundary only into words containing an error.
  • Timing comes from the event's own timeStamp where available, falling back to performance.now(). Never the wall clock.
  • Auto-repeat, paste, and IME composition are rejected at the boundary and never reach the engine.

Metrics, defined once

All derived from the event log after the fact, deterministically. Nothing sampled live — which is exactly what makes verification possible.

MetricDefinition
rawWpm(all typed chars / 5) / minutes
wpm(correct chars / 5) / minutes — net WPM, no error subtraction
accuracycorrect keystrokes / total keystrokes, first attempt
consistency100 × (1 − σ/μ) across per-second WPM samples
charStatscorrect / incorrect / extra / missed

Integrity pipeline

The server owns the text. The client asks for a test; the server issues an id and a seed and remembers both. Word lists are generated from that seed by shared code — so the client can no longer tell the server what it typed, only how.

  • Regenerate the word list from the stored seed.
  • Replay the submitted event log through the same engine the browser ran.
  • Recompute results and compare against the client's claim. Any mismatch is a rejection.
  • Check the human-ness of the timing: monotonic timestamps; duration consistent with server-side issue-to-receipt; keydown/keyup hold times in human range; no sub-human intervals or sustained impossible bursts; a coefficient-of-variation floor, because people are never that regular and scripts always are; same-finger bigrams above physical minimums; per-user and per-IP rate limits.
  • Band by score. Results above a high-water mark land in flagged and pass a stricter statistical review before they appear publicly.

Every test stores verification: verified | flagged | rejected with its reason. Leaderboards read verified only. Guest tests never rank.

Analytics & coaching

Computed, not guessed. No model calls anywhere in this pillar.

  • Per key — median latency, error rate, sample count. The median, not v1's single worst keystroke.
  • Per bigram — transition latency. This is the real signal: th is fast, yp is slow, and your slow set is personal.
  • Error taxonomy — substitution (and whether the wrong key was physically adjacent), transposition, insertion, omission, capitalisation.
  • Biomechanics — hand balance, finger load, same-finger bigram frequency, alternation ratio.
  • Rhythm — warm-up curve, fatigue decay across a test, consistency over time.
  • Weakness → drills — synthesized word lists weighted toward your worst bigrams, drawn from real dictionary words so drills read as English rather than gibberish.

This is the pillar's entire justification: no other typing site keeps per-keystroke timing at this fidelity, so no other typing site can tell you this.

The Line

One idea, expressed relentlessly. It is the caret, the WPM curve, the underline in the wordmark, the page transition, the progress bar, the rank marker. That repetition is what makes an identity read as designed rather than assembled.

During

A thin luminous path is drawn beneath the text in real time. Height is instantaneous WPM; hue shifts with accuracy. One animated path on a 2D canvas. Costs nothing, distracts no one.

At the finish

The text dissolves upward and the Line detaches, scales, and settles into the results chart. One continuous transition — no cut, no route change. The chart was never generated. You drew it.

Ever after

Every test you have taken is a Line. Your history is a wall of them, your best one lit. Racing your past self is two Lines drawn at once.

Rules of engagement

  • Nothing animates behind text while a key can be pressed.
  • The test route ships no WebGL and no motion library. The Line is raw requestAnimationFrame.
  • WebGL is lazy-loaded on the landing, the results backdrop and the analytics view only, each with a static fallback.
  • prefers-reduced-motion is a first-class path, not a disable switch. Every animation is interruptible; nothing blocks input.
